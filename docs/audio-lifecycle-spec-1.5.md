### AUD-49 [新增] 门控原语的生命周期契约

门控过渡（AUD-46）是一个可能跨多 tick 存活的状态对象，因此适用与
AUD-9 v1.3 相同的判据：漏执行一次的后果不得是永久性的。

1. **推进者归属**：门控的推进必须由 tick 线程在每 tick 的无条件段执行
   （converge() 之后、任何早退之前）。禁止把推进放在任何带早退条件的方法
   内部，禁止依赖播放线程推进。
2. **超时兜底**：每个门控必须携带截止时间，默认 fadeOutMillis + 500ms。
   超时后无条件执行 action 并把包络拉回 1.0，同时记录一条固定格式日志。
3. **取消即复位**：任何清除门控的路径（stopMusic、invalidatePlayback、
   reset）都必须同时把该门控占用的包络 target 与 current 复位到 1.0。
   清除门控而不复位包络等同于制造永久静音。
4. **禁止静默丢弃**：门控槽被占用时，新请求必须排队或显式失败并由调用方
   回滚其局部状态。禁止 return 吞掉请求而让调用方以为动作已生效。
5. **action 的完整性**：action 必须包含过渡的全部副作用。若"停旧"与"起新"
   分处两个 tick，则淡入不得由门控触发，而必须由新声源的起播触发。
   淡入一段无声源的静默不算完成过渡。

### AUD-48 [修订 v1.1] 拆链必须门控

滤镜链的移除是 mix 包络归零后的 action，不得与 setMixTarget(0) 同 tick
发生。mix 的语义是"滤镜链输出的干湿比"，因此在 mix > 0.001 期间旧链必须
继续存在并被求值。相应地：

- mix 的稳态默认值为 0.0（无滤镜），激活时 0→1，停用时 1→0 且归零后才拆链
- 空链（processors.isEmpty() && transitionFrom == null）必须直通，
  禁止逐采样求值

### AUD-30 [追加] 探针字段

`world.line` 行追加 `underruns=<n>`：写入前 `available() == getBufferSize()`
的累计次数，随每次起播清零。
